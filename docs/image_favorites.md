# 图片收藏

收藏数据库位于当前有效下载目录的 `image_favorites.db`。独立原图存入
`image_favorites/originals/`，WebP 缩略图存入 `image_favorites/thumbnails/`。
备份整个下载目录即可保留收藏；普通数据备份及 WebDAV 不包含收藏。

## 数据与状态

- `ImageFavorite` 区分阅读漫画身份与实际下载漫画 ID。
- 下载引用保存漫画 ID 和相对于漫画目录的图片路径，包括必要的章节目录。
- 独立图片使用收藏身份的 SHA-256 作为文件名，保留原格式，另外保存在线 URL。
- 文件引用与阅读元数据不存本机绝对路径。文件路径通过当前下载记录解析，漫画目录重命名后继续有效。
- `imageFavoritesRepositoryProvider` 注入当前下载服务；`imageFavoritesProvider` 管理操作与全局列表，筛选、分组、数量和缩略图使用派生 Provider。
- 取消收藏不会删除下载原图。删除漫画、章节或仅删除下载记录前，先转存被收藏的原图；转存失败中止删除。
- 目录迁移暂停下载，等待待写队列及缩略图任务完成，关闭数据库，复制并校验，重新打开目标连接后才清理原目录。

## 收藏页显示

作品及分组入口按最近一次新增图片收藏的先后排序，最近收藏的作品在前；
同一作品内按阅读方向的章节顺序、章内页码排列，右上角可反转整个图片列表。
重复收藏已有图片不改变顺序，删除后按剩余记录计算最近收藏顺序。
作品身份由来源和漫画 ID 确定，同名作品保持独立。

卡片显示作品名、章节名（缺少时使用章节序号）及页码。
新记录在 `otherInfo` 中保存 `hasEp`、`chapterName`、`chapterStep`，旧记录从
`jmEpNames`、`eps` 解析；没有章节的作品只显示页码。

卡片右上角及菜单的“查看原图”使用本地图片查看器，按当前筛选和排序切换已收藏图片。
图集使用打开时的列表快照，每次切图通过仓库解析最新原图位置，不预先加载整个图集。
单张文件失效时仍可切换其他图片，卡片主体保留打开漫画的操作。

## 缩略图

从 `pixez_flutter` 移植独立的 cwebp 工具封装、缩放参数及静态编码流程。
Windows 安装包随附 `assets/executables/cwebp.exe` 和其许可文件，不依赖参考项目的安装路径。

缩略图从中心裁切为 **宽:高 = 9:16**，常规输出为 **432 × 768**，小图按整比例降低输出尺寸。
小于一个 9 × 16 单元的极小图使用最小输出尺寸。质量为 80，压缩方法为 4，保留透明通道，移除原图元数据。
静态图片由 cwebp 裁切、缩放和编码；其他格式及动图使用首帧生成临时 PNG，再编码为 WebP。
同时最多运行两个编码任务，单条收藏共享生成任务，进程超时为 30 秒。

显示时验证磁盘缓存的实际 WebP 格式、比例和解码结果，缺失或损坏则重新生成。
清除图片缓存会移除缩略图，不删除收藏数据库或独立原图。编码工具不可用时提供限定解码尺寸的原图临时预览。

## 一次性迁移

迁移工具为 `tool/migrate_image_favorites.py`，依赖 Python 和 Pillow。必须先退出应用。
默认只检查，添加 `--apply` 才执行实际迁移。输入目录必须明确传入，例如：

```powershell
python tool/migrate_image_favorites.py --old "C:\Users\Administrator\AppData\Roaming\com.github.pacalini\pica_comic" --root "E:\Pictures\picacomic_downloads" --apply
```

工具优先使用下载漫画身份和旧地址中的真实文件名定位原图，不能定位时使用旧独立副本。
保留章节、页码，清理本机地址，并补全旧 JM 记录的章节 ID。
在 `image_favorites/migration_backup/` 保存旧历史数据库、旧图片及迁移报告。
新库、全部原图和缩略图验证完成并安装后，才移除旧历史库中的收藏表和旧图片目录。
新库已经存在时拒绝覆盖，不在应用运行时兼容旧格式。

若安装阶段因文件占用中断，可以在退出应用后指定 `--apply --resume <临时迁移目录>` 接续。
工具会重新检查数据库、缩略图、旧图片备份及记录身份，再完成安装与清理。

执行迁移后应使用新构建的应用。旧应用仍依赖旧历史库收藏表。
