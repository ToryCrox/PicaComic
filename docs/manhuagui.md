# 漫画柜

内置来源标识为 `manhuagui`，使用 `https://www.manhuagui.com/`。首次启用会追加一个“漫画柜”探索入口，之后保留用户的隐藏和排序设置。探索提供最近更新、连载和完结；分类独立放在首页“分类”的漫画柜 Tab 中，支持地区、剧情、受众、年份、字母、进度组合筛选和排序。分类入口首次升级追加一次，之后保留隐藏及排序。详情操作栏支持用系统默认浏览器打开原网页。

## 章节与阅读

`ComicInfoData.chapterGroups` 记录网站分组和有序章节 ID，`chapters` 保持完整目录。目录包含网页折叠区间；压缩目录和图片脚本由纯 Dart 解析，不运行网页脚本。网站目录的区间按旧到新排列，各区间内部倒序，解析时逐区间还原正序，避免新章节后接回旧章节。各分组在详情、阅读目录及下载选章中分模块显示，默认显示二十章，独立展开、收起或倒序。详情目录融入整页滚动。

漫画柜阅读器及连续滚动共用组内相邻章节规则；组末停止，用户可从章节菜单手动切换分组。历史数据库版本 2 增加可空章节 ID 和已读 ID 列，旧历史升级时保留原位置。该能力仅由支持稳定章节标识的来源写入。

## 下载

下载选章支持跨组选择，每个分组标题旁提供下载整组的按钮，已下载章节不会重复加入。独立下载类型追加在枚举末尾，目录命名为 `chapter-<章节ID>`，更新目录时按 ID 重映射下载状态；网站移除但已经下载的章节继续保留在本地分组。暂停任务保留链接、选章和目录映射，空章节会重试并报错；图片签名失效后重新获取所在章节的链接。

## 评论

无需账号即可查看最新评论、热门评论和引用回复链。排序切换与返回、评论标题同行。列表接近底部自动追加下一页，短列表自动补满视口；失败保留已有内容并提供重试。切换排序回到第一页，通过请求代次隔离旧响应。暂不提供发表、点赞和登录。

## 验证

解析样例位于 `test/fixtures/manhuagui/`，包含来源于示例漫画的压缩目录、章节脚本，以及裁剪后的列表和搜索结构。

日常测试不依赖外网。需要真实站点联测时，在 PowerShell 中执行：

```powershell
$env:PICA_MANHUAGUI_LIVE = '1'
fvm flutter test test/network/manhuagui_live_test.dart
Remove-Item Env:PICA_MANHUAGUI_LIVE
```

联测覆盖搜索、分类分页、最近更新、分组详情、图片下载及最新/热门评论；站点调整结构或网络不可达会使联测失败。
