# 日志查看器使用说明

## 功能说明

日志查看器允许你在浏览器中实时查看应用的日志输出。它会在桌面平台（Windows/Linux/macOS）自动启动一个 HTTP 服务器，提供 Web 界面查看日志。

## 使用方法

### 1. 构建 Web 应用（首次使用）

在首次使用前，需要先构建 Web 应用：

```bash
dart scripts/build_log_viewer_web.dart
```

构建产物会自动复制到 `assets/log_viewer_web/` 目录。

### 2. 启动应用

正常启动应用即可。在桌面平台，日志查看器服务器会自动启动。

### 3. 访问 Web 界面

在浏览器中访问：`http://localhost:8080`

如果端口 8080 被占用，服务器会自动尝试下一个可用端口，启动信息会在控制台输出。

## 功能特性

- **实时日志流**：通过 SSE（Server-Sent Events）实时推送日志
- **历史日志查看**：可以查看应用启动后的所有日志
- **日志过滤**：支持按日志级别和关键词过滤
- **日志搜索**：支持搜索日志内容
- **清空日志**：可以清空当前显示的日志

## 技术实现

- **Server 部分**：运行在 Flutter App 进程内，提供 HTTP 服务器和 API
- **Web 部分**：独立的 Flutter Web 应用，运行在浏览器中
- **通信方式**：通过 HTTP/SSE 协议通信

## 注意事项

1. 仅在桌面平台（Windows/Linux/macOS）可用
2. 需要先构建 Web 应用才能使用
3. 如果端口被占用，服务器会自动尝试下一个可用端口
4. 日志数据来自 `logMemoryOut`，与应用的日志系统完全集成

## 故障排除

### 无法访问 Web 界面

1. 检查控制台是否有启动信息
2. 确认端口是否被占用
3. 检查防火墙设置

### 看不到日志

1. 确认应用正在产生日志
2. 检查浏览器控制台是否有错误
3. 尝试刷新页面
