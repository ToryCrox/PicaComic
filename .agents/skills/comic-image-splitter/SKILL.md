# 漫画长图切割

当用户要求切割漫画长图、保留原图格式并重排页码时使用本 skill。不要把任何一次任务的目录保存为默认值，也不要递归处理子目录。

## 操作规则

- 每次都要求明确的输入目录；运行脚本时必须传入 `--input-dir`。
- 脚本默认处理目录顶层、数字文件名的 `.jpg`、`.jpeg`、`.png` 和 `.webp` 图片。遇到非数字图片名、重复数字编号、格式与扩展名不符或动画图片时应停止并报告，不能静默跳过漫画页。
- 默认参考宽度为 2160 px，单段等效高度上限为 6000 px。等效高度按 `原图高度 × 2160 ÷ 原图宽度` 计算；切割不缩放图片。
- 超限图片按 `ceil(等效高度 ÷ 上限)` 决定段数，先均分高度，再尝试将切口贴近横向近白留白。只有当留白切口能让各段保持在均分目标的 75% 以上且不超过上限时才采用；否则使用均分切口，避免出现很短的尾段。
- 切片从上到下输出，沿用源图扩展名；所有图片按原数字顺序从 `--start-index` 连续编号，默认从 0 开始。未切割图片逐字节复制；切片以相同格式重新编码，不做格式转换。PNG 切片保持原有色彩模式与透明通道，并以无损方式保存。
- 默认只预览，不修改文件。用户明确要求执行后才添加 `--apply`。执行时先在输入目录同级暂存所有结果并验证可读性、尺寸、格式和编号；全部通过后才将原图移入输入目录内的 `back/<时间戳>/`，再放入新结果。失败时回滚已移动文件。
- 依赖 Python、Pillow 和 NumPy。缺依赖时说明缺少项，不要自动安装。

## 使用

先预览本次明确指定的目录：

```powershell
python .agents/skills/comic-image-splitter/scripts/split_comic_images.py --input-dir "<用户提供的目录>"
```

用户要求实际处理时，使用相同的显式目录并添加 `--apply`：

```powershell
python .agents/skills/comic-image-splitter/scripts/split_comic_images.py --input-dir "<用户提供的目录>" --apply
```

用户指定其他切割参数时，可通过 `--reference-width`、`--max-equivalent-height` 和 `--start-index` 覆盖默认值。处理完成后报告切割数量、输出总数、编号范围和 `back/<时间戳>/` 备份目录。
