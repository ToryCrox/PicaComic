# 漫画长图切割

当用户要求切割漫画长图、保留原图格式并重排页码时使用本 skill。不要把任何一次任务的目录保存为默认值。

## 操作规则

- 每次都要求明确的输入目录；运行脚本时必须传入 `--input-dir`。用户在当前请求中已给出父目录并明确要求处理子目录时，不要重复询问每个章节目录。
- 默认只处理输入目录顶层。用户明确要求“所有章节”“所有子目录”或递归处理时添加 `--recursive`，脚本自动遍历，含图片的父目录也作为独立章节处理；每章独立编号，不展平章节。跳过 `back`、系统备份目录、`tmp`/`temp`、脚本暂存目录、隐藏目录及目录链接（含 Windows 目录联接）；输入根目录也不能是目录链接。
- 默认备份统一放在系统“下载”目录的 `PicaComic Image Splitter Backups` 中，不能在输入目录树中创建备份。普通原图直接放在每章备份目录 `back/`；所有章节的空白页统一放入同一个 `blank_pages/` 汇总目录，再按“章节名+章节绝对路径哈希”分子目录并保留原始文件名，避免不同章节同名原图冲突，方便用户集中复核。递归输入时汇总目录按输入根目录名和绝对路径哈希生成；单章输入时按章节父目录名和绝对路径哈希生成，使同一漫画下逐章运行仍汇总到一起。普通备份路径按“章节父目录名+父目录绝对路径哈希 / 章节名+章节绝对路径哈希 / back”自动计算。用户指定 `--backup-dir` 时，单章将其作为普通备份目录，汇总目录为其下的 `blank_pages/`；递归时普通备份按“输入根目录名+路径哈希 / 章节相对路径 / back”保存，空白页统一放在“输入根目录名+路径哈希 / blank_pages/”。重切默认使用章节记录中的原备份路径，不能因临时输入目录改变它。
- 宽度筛选用 `--max-width N`，只处理宽度 **≤N px** 的图片，包含边界；`--max-width 2160` 与计算等效高度的 `--reference-width 2160` 是两个独立参数。排除 WebP 用 `--exclude-webp`，扩展名匹配不区分大小写。不满足条件的图片不裁切、不重编码、不重命名、不备份或移入回收站；预览列出文件名和跳过原因，全部被排除时该章不写入任何内容。
- 再次处理使用 `--resplit`，不能直接重切旧切片。脚本用章节中的 `.comic-image-splitter.json` 记录原图名称、字节数、SHA-256、对应输出、普通备份路径、共享 `blank_backup_dir` 以及空白页的 `backup_subdir` / `backup_chapter`；空白页会按记录从公共汇总目录定位。兼容旧记录：缺少共享目录字段或章节归档名时，从旧的 `back/blank_pages/` 读取。筛选时只替换选中原图对应的旧结果，未选中的原图或切片保持原样，也可同时处理章节内尚未切割的数字原图。原图备份及记录中的旧切片缺失、哈希变化、额外切片来源不明或页号冲突时停止该章。递归批次中未处理过的章节仍正常处理。
- 旧版章节没有对应记录时，仅在顶层全部为切片、备份直接层级有唯一数字原图清单、本次筛选没有排除任何原图，且原页数量、格式与切片分组对应、分段序号连续时允许整章重切；局部重切或混合目录无法确认对应关系，必须停止并报告。全部被筛掉时保持该章原样。`*_before_repair`、`*_before_resplit` 永远不能当作原图，不从旧切片猜测拼回原图。
- 重切先从已校验备份生成只读预览；执行时将选定原图复制到本次独立临时输入目录，逐张核对字节数与 SHA-256，再使用同一计划生成和验证新结果。新结果通过后，将旧切片复制到原外部 `back/`，校验后移入回收站；归档名添加 `_before_resplit`，重名追加序号，不覆盖。再放入新结果并更新记录。普通原图及旧切片归档均在外部 `back/` 直接层级，空白页原图统一进入公共 `blank_pages/<章节名-哈希>/`。共享副本校验成功后，旧章节备份目录中同内容的空白页重复副本移入回收站，避免空白页再次散落在各章节目录；其他普通原图备份不动。传入 `apply_plans` 的原图必须全部是输入目录的直接子文件，禁止直接传入外部原图对象。
- 脚本默认处理目录顶层、数字文件名的 `.jpg`、`.jpeg`、`.png` 和 `.webp` 图片。遇到非数字图片名、重复数字编号、格式与扩展名不符或动画图片时应停止并报告，不能静默跳过漫画页。
- 默认跳过纯白或近白空白页：将图片按实际显示效果合成到白色背景（包括 PNG 的调色板透明信息）后，只有每个像素的 RGB 通道都不低于 `250` 才判定为空白页，以兼容 JPG 压缩产生的轻微灰度。任一像素存在低于阈值的通道，整页保留。预览列出被跳过的文件名和公共 `blank_pages/` 汇总目录；执行时将校验过的原图副本放入 `blank_pages/<章节名-哈希>/<原文件名>`，再把章节中的源文件移入回收站，不生成切片。所有章节的空白页必须汇总在同一个 `blank_pages/` 根目录下，不能分散到各章节备份目录；章节子目录仅用于防止原文件名冲突。之后 `--resplit` 从处理记录定位并校验它。全章连续编号模式让剩余页号连续；筛选模式保持原始页号，不压缩空缺。用户要求保留空白页时传入 `--keep-blank-pages`。
- 只缩短上下边缘连续的大块近白区域，以及图片宽度方向几乎全白的过宽横向留白；左右边缘绝不裁切，非白背景和普通内部留白保持原样。压缩大横向留白时保留 `10%` 图片宽度的间距（限制在 48–160 px），检测时为画格内容保留安全边距。按处理后的高度规划分段；参考宽度为 2160 px，默认等效高度范围为 3000–5000 px。等效高度按 `图片高度 × 2160 ÷ 图片宽度` 计算；不缩放图片。
- 超限图片按目标平均等效高度约 4000 px 选择段数，优先搜索完整横向留白，再选择低墨量行；切口避开识别到的文字字形区域。若切口无法满足段长限制，会将搜索范围扩展到所有可行位置，并对高墨量行增加代价。仅在候选无法组成可行计划时才回退到均分点。目标下限与上限可通过 `--min-equivalent-height` 和 `--max-equivalent-height` 设置。若原图本身太短，数学上无法让每段同时满足上下限，则优先保证不超过上限，并在预览中提示；执行校验使用相同的可行性判断，允许这些不可行切片低于下限，但仍拒绝超过上限。预览必须显示实际选中的切口坐标和“留白/低墨量/均分”来源，执行时使用同一份计划。
- 不筛选时按输入数字顺序分配连续页号，默认从 1 开始；指定宽度筛选或排除 WebP 时保留原始数字页号，如 `3.jpg` → `3-0.jpg`、`3-1.jpg`，避免与未处理页混序。局部重切也保留原始页号，发现与保留页冲突就停止。这些模式不能同时指定其他 `--start-index`。分段序号从 0 开始，单页也使用 `页号-0`。项目阅读器已有 `sortedByName()` 自然数字排序和按阅读页序取图，无需修改阅读器。未切割且未裁边的图片逐字节复制；需要裁边或切割的图片沿用原格式重新编码。PNG 保持原有色彩模式与透明通道并无损保存。
- 默认实际执行：收齐明确的输入目录和处理范围后，脚本命令必须添加 `--apply`。只有用户明确要求“预览”“检查方案”或“先看看”时才省略 `--apply`；预览结束后不再询问是否执行，除非出现来源不明、冲突或其他需要用户选择的阻断项。脚本先预览全部章节，任一章无法确认来源或存在冲突时整批不写入。执行逐章隔离暂存和提交：验证切片可读性、尺寸、格式和编号后，将普通原图备份到每章 `back/` 根目录、空白原图备份到输入范围共用的 `blank_pages/<章节名-哈希>/`，再放入新结果；新结果全部落盘后才将章节内数字原图移入回收站，最后更新章节记录。共享空白页副本经哈希与字节数验证后，旧章节备份中的同内容重复副本才可移入回收站；普通原图备份不动。同名原图备份仅在哈希一致时复用，不同内容必须停止。失败时尽量恢复原图、旧切片并回滚新结果，已完成章节不回滚，后续章节停止；外部备份始终保留。只清理本次新建且路径已核验的暂存路径，清理前再次核对其原图或备份哈希，不能含唯一原图。临时文件、失败结果和暂存目录使用回收站；失败时保留原路径并报告，不回退为永久删除。
- 优先在完整横向白色留白处分割，可减少切口穿过画格或人物的概率；这只保证源图切点更合适，不保证阅读器把独立图片无缝合成一张图。阅读器可能因缩放、滚动位置和物理像素对齐显示一像素细缝。不要通过擅自重编码白边、加重叠或修改漫画内容来掩盖这种显示缝。
- 依赖 Python、OpenCV、Pillow 和 NumPy；非 Windows 执行还需要 `send2trash`。缺依赖时说明缺少项，不自动安装。

## 使用

用户只要求预览时，省略 `--apply`：

```powershell
python .agents/skills/comic-image-splitter/scripts/split_comic_images.py --input-dir "<用户提供的目录>"
```

用户提供目录并要求切割、未明确要求预览时，默认实际处理；必须使用相同的显式目录并添加 `--apply`：

```powershell
python .agents/skills/comic-image-splitter/scripts/split_comic_images.py --input-dir "<用户提供的目录>" --apply
```

递归预览父目录，只处理宽度不超过 2160 的非 WebP 图片：

```powershell
python .agents/skills/comic-image-splitter/scripts/split_comic_images.py --input-dir "<用户提供的父目录>" --recursive --max-width 2160 --exclude-webp
```

默认执行时在命令中添加 `--apply`；明确要求预览时省略它。要求从原图重新处理时再加 `--resplit`，实际重切命令仍需添加 `--apply`；省略 `--apply` 时仅预览并保留旧结果原样。递归时脚本自动生成每章备份路径，不需要逐章调用。

要求保留纯白或近白空白页增加 `--keep-blank-pages`；等效高度参数用 `--reference-width`、`--min-equivalent-height` 和 `--max-equivalent-height`。只有不筛选且不做局部重切时才能用 `--start-index` 修改连续编号起点。

处理完成后报告章节数、各章切割数量、筛选跳过及空白页跳过数量、唯一的空白页汇总目录、输出总数、编号范围和外部备份路径。验证脚本的回归测试位于 `test/skills/comic_image_splitter_test.py`，使用临时合成图片及隔离回收站替身，不处理用户漫画目录。
